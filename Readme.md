# CCPLC CCTV | Hybrid TV

একটি মডার্ন এবং রেসপন্সিভ হাইব্রিড ওয়েব টিভি অ্যাপ্লিকেশন, যা আপনার লোকাল নেটওয়ার্ক বা এম থ্রি ইউ (M3U) প্লেলিস্ট থেকে সরাসরি লাইভ টিভি চ্যানেল স্ট্রিম করতে সহায়তা করে।

🌐 **লাইভ সাইট ভিজিট করুন:** [https://cctvccplc.github.io/tv](https://cctvccplc.github.io/tv)

---

## 🚀 মূল বৈশিষ্ট্যসমূহ (Key Features)

* **হাইব্রিড প্লেয়ার সাপোর্ট:** ভিডিও জেএস (Video.js) এবং আইফ্রেম (Iframe) সাপোর্টের মাধ্যমে যেকোনো ফরম্যাটের স্ট্রিম বা এমবেডেড চ্যানেল চালানো যায়।
* **ক্যাটাগরি অনুযায়ী ফিল্টার:** খেলাধুলা, খবর, বিনোদন এবং অন্যান্য ক্যাটাগরিতে চ্যানেলগুলো সুন্দরভাবে সাজানো।
* **রিয়েল-টাইম সার্চ:** সার্চ বারের মাধ্যমে আপনার পছন্দের চ্যানেলটি মুহূর্তেই খুঁজে বের করুন।
* **ডাইনামিক মারকুই টিকর:** রিয়েল-টাইম তারিখ, সময় এবং প্রতিষ্ঠানের বিভিন্ন স্লোগান বা তথ্য স্ক্রিনে প্রদর্শিত হয়।
* **নিরাপত্তা সুরক্ষা:** রাইট-ক্লিক ডিজেবল এবং কোড প্রটেকশন মেকানিজম যুক্ত।
* **রেসপন্সিভ ডিজাইন:** মোবাইল, ট্যাবলেট এবং ডেস্কটপ ডিভাইসে চমৎকারভাবে কাজ করে।

## 🛠️ টেকনোলজি স্ট্যাক (Tech Stack)

* **HTML5 / CSS3** (Custom Modern Variables & Grid Layout)
* **JavaScript (ES6+)**
* **Video.js** (v7.20.3)
* **Google Fonts** (Hind Siliguri & JetBrains Mono)

## ⚙️ ইনস্টল ও রান করার নিয়ম

আপনার লোকাল মেশিনে এটি চালাতে চাইলে নিচের ধাপগুলো অনুসরণ করুন:

1. এই রিপোজিটরি ক্লোন করুন অথবা কোডগুলো ডাউনলোড করুন।
2. একটি `index.html` ফাইল তৈরি করে সম্পূর্ণ সোর্স কোডটি পেস্ট করুন।
3. যেকোনো মডার্ন ব্রাউজারে ফাইলটি ওপেন করুন অথবা লাইভ সার্ভার (Live Server) ব্যবহার করুন।
